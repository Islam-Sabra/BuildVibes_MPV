### Server
Migration `20261201120000_review121_key_people.sql`.
- **Tables:** `space_key_roles` and `space_key_holders` have RLS, with no policies and no grants. Members read and write only through the functions.
- **Reading:** `space_key_people(p_space)` is for every member, Viewers included; anyone else gets 42501. It returns:
  - each role, in order;
  - its people as the app's person embed (name, title, company), with the note;
  - `can_call` for each person, never the number;
  - `seen`, for KP2.
- **Writing:** `save_key_role`, `delete_key_role` and `reorder_key_roles`.
  - They are security definer with `search_path=''`, and only the Space admin may call them.
  - Up to 6 roles, else 54000; up to 2 people a role, else 54000.
  - Each holder must be a current member and appear once (22023).
  - Limits: name 40 characters, Call for 120, note 24.
- **A holder leaves:**
  - The trigger covers a leave, a removal (`left_at`), or a deleted membership; the person is taken off the role.
  - If that empties the role, each Space admin gets one Activity line, `key_role_empty` ("Safety officer has no one now"), with no push.
- **KP2:** `space_members.key_people_seen_at`.
  - Everyone already in a Space is backfilled as seen, and whoever makes a Space is seen.
  - `mark_key_people_seen(p_space)` sets it.
- **The phone number:**
  - `profiles.phone` (E.164) and `phone_visibility` (`nobody` by default / `spaces` / `spaces_and_dms`).
  - `profiles` now has **column grants**: every column but `phone`, so `select phone` gives 42501. A new `profiles` column from now on needs its own grant.
  - `set_my_phone` checks E.164, a market the pack knows (longest dial code first), the national length and the mobile prefixes. `my_phone()` returns my number and my choice.
- **`person_phone(p_profile, p_space)`:**
  - It returns the number only when the owner's choice allows it and both people are current members of that Space.
  - With `spaces_and_dms`, a direct message counts, but only once the owner has it open (a request doesn't count).
  - Blocked or hidden accounts get null.
  - It allows 30 calls a day per caller (54000), under an advisory lock; reads older than a day are deleted on each call.
- **Market pack:** `markets.key_role_suggestions`. Kuwait and Egypt have Safety officer «ضابط السلامة», Project engineer, Site manager, Site nurse and Storekeeper. A test checks that no name uses «مسؤول».
- **Data export:** it now includes the number and the choice. It copies the whole profile row, so nothing extra was needed.
